# Carl's Portfolio

Personal portfolio site for Carl - BS Information Technology student building IoT and AI dashboards.

I built this with vanilla JS and Vite. The animations use GSAP. and images are optimized with Sharp at build time.

## Run

```bash
npm install
npm run dev      # dev server
npm run build    # production build to dist/
npm run preview  # preview the build
```

Source lives in `index.html`, `src/main.js` and `src/style.css`. Raw assets are in `assets/`; optimized versions are generated into `assets/optimized` on `dev` and `build`.
